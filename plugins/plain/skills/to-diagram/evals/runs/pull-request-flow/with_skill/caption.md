Notice that the owner is involved only twice: approving the spec at the start and trying the preview build near the end. Between those, the agent and two reviewers (Karen, our automated reviewer, and a second AI reviewer) work on their own. If either reviewer finds a problem, the change goes back to the build step, so nothing reaches the preview until both reviewers pass it. The change merges to the staging branch first, and only later does staging merge to the main branch.

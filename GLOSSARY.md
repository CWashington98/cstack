# cstack

A personal collection of Claude Code plugins and skills, shared across projects.

## Language

**claims-auditor**:
Our automated reviewer agent. It checks what was actually built against what was claimed, and returns "ready" or "not ready". It was called Karen until October 2026, so older documents use that name.

**cstack**:
This repository: a collection of Claude Code plugins that every project installs.

**pstack**:
Lauren Tan's published set of Claude Code and Cursor skills. We point at four of them.

**T3 Code**:
A desktop app for running Claude Code sessions, used alongside the terminal.

**GIVEN**:
In a spec scenario, the situation before anything happens. Specs written in the OpenSpec format use capital GIVEN, WHEN, THEN and AND as fixed labels.

**WHEN**:
In a spec scenario, the action someone takes.

**THEN**:
In a spec scenario, what must be true afterwards. A test for the scenario checks exactly this.

**AND**:
In a spec scenario, one more line of the same kind as the line above it.

**SHALL**:
In a spec requirement, "must". SHALL NOT means "must not".

**NOT**:
Used in SHALL NOT, meaning "must not".

**ADDED**:
In an OpenSpec change, the heading for requirements this change adds.
